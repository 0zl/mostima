Mostima - DeepSeek Model Provider Rankings


- What is this?
It's a table that ranks various api providers that hosted DeepSeek model. The goal is to find the best provider that can save money while maintaining good quality.

- So it's yet another leaderboard?
Perhaps, yes. Just a simple one without too many academic metrics.

- Who is this for?
I created this mainly for myself, but the goal is to find cheapest provider for my creative writing needs and roleplay scenarios.

- How often do this get updated?
Whenever I have time to do so. You can help by submitting a PR on GitHub.

- How do I read this?
Each provider is ranked by a score that I calculated based on input/output price, precision/quality, and features. The higher the score, the better.

      Some FAQs:

      • Q: Why did you not include OpenRouter?
      • A: I prefer using the API directly from the provider rather than through a rotating proxy or similar intermediary, as it sometimes offers better pricing.

      • Q: Why did you not include Chutes?
      • A: Chutes pricing is monthly based with the cheapest plan only gives you 300 requests per day. But, you can try Chutes if you want.

      • Q: How do you determine the quality/precision score?
      • A: It's based on my own experience and some rough tests and simple observations. It's good enough for my needs.

      • Q: Where can I find the score for each quantization type?
      • A: You can find the scores in the YAML files for each model version on GitHub.

      • Q: Why is provider X not listed?
      • A: I only include providers that I know of and have pricing info available. If you know any other providers, you can submit a PR on GitHub.

      • Q: Why I can't register for SiliconFlow account?
      • A: SiliconFlow is a China-based provider which some phone number countries can't receive their SMS verification code.
